# Web Applications

Web-based interfaces for the health management platform.

## Applications

### Doctor Portal
- **Location**: [doctor/](doctor/)
- **Description**: Web interface for healthcare providers
- **Tech**: HTML, CSS, JavaScript, Node.js server

### User Portal
- **Location**: [portal/](portal/)
- **Description**: Web interface for end users
- **Tech**: HTML, CSS, JavaScript, Node.js server

## Development

Each application has its own `package.json` and can be run independently.

### Doctor Portal
```bash
cd doctor
node server.js
```

### User Portal
```bash
cd portal
node server.js
```
