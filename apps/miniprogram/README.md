# WeChat Mini Program (微信小程序)

WeChat-based health management mini program.

## Features

- Health data tracking
- Chat interface
- Moment/timeline
- Health reminders
- Article reading
- Health reports
- User profile management
- Login/authentication

## Project Structure

- `pages/` - Mini program pages
  - `chat/` - Chat interface
  - `chat-detail/` - Chat detail view
  - `moment/` - Timeline/moments
  - `reminder/` - Health reminders
  - `add-reminder/` - Add new reminder
  - `article/` - Article list
  - `article-detail/` - Article detail view
  - `health-report/` - Health reports
  - `history/` - History view
  - `profile/` - User profile
  - `login/` - Login page
- `assets/` - Static assets (images, icons)
- `app.json` - Mini program configuration
- `app.js` - Mini program entry point

## Development

Requires WeChat Developer Tools.

1. Open WeChat Developer Tools
2. Import this project
3. Configure `project.config.json` with your AppID
4. Start development

## Configuration

- `app.json` - Page routes and window configuration
- `project.config.json` - Project settings
- `sitemap.json` - Search indexing configuration
