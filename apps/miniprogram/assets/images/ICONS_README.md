# 文章详情页所需图标资源

请在 `miniprogram/assets/images/` 目录下添加以下图标文件：

## 必需图标

1. **back.png** - 返回按钮图标
   - 尺寸：40x40rpx
   - 颜色：深灰色 (#333)
   - 用途：导航栏返回按钮

2. **like.png** - 未点赞图标
   - 尺寸：44x44rpx
   - 颜色：灰色 (#666)
   - 用途：点赞按钮（未点赞状态）

3. **like-active.png** - 已点赞图标
   - 尺寸：44x44rpx
   - 颜色：绿色 (#4CAF50)
   - 用途：点赞按钮（已点赞状态）

4. **collect.png** - 未收藏图标
   - 尺寸：44x44rpx
   - 颜色：灰色 (#666)
   - 用途：收藏按钮（未收藏状态）

5. **collect-active.png** - 已收藏图标
   - 尺寸：44x44rpx
   - 颜色：绿色 (#4CAF50)
   - 用途：收藏按钮（已收藏状态）

6. **share.png** - 分享图标
   - 尺寸：36x36rpx
   - 颜色：白色 (#fff)
   - 用途：分享按钮

7. **default-avatar.png** - 默认头像
   - 尺寸：80x80rpx
   - 用途：作者头像占位图

## 图标设计建议

- 使用简洁的线条风格
- 保持图标风格统一
- 确保在不同背景下清晰可见
- 可以使用 iconfont 或 SVG 格式以获得更好的显示效果

## 临时解决方案

如果暂时没有图标资源，可以：
1. 使用文字代替图标（如 "←" "♥" "★" "↗"）
2. 使用 Unicode 字符
3. 从免费图标库下载（如 iconfont.cn、flaticon.com）
